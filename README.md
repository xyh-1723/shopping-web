# 小小商城 · Spring Boot 从零学习项目

一个可以实际点击、下单、取消、模拟支付的小商城。用 **6 件商品 + 1 条完整订单链路**，学习 Spring Boot 常用知识，以及幂等、并发和可靠异步处理。

## 先运行，再读代码

需要 **JDK 21** 和 **Maven 3.6.3+**。无需 Node.js、MySQL、Redis 或 RabbitMQ。首次构建需要联网下载 Maven 依赖。

Windows：在本目录双击 `start.cmd`，或在终端执行：

```powershell
cd F:\Codex\projects\springboot-learning-mall
.\start.cmd
```

通用启动命令（在项目根目录执行）：

```shell
mvn spring-boot:run
```

访问 **http://localhost:8080**。演示账号 `student`、`classmate`（顾客）与 `admin`（店员，多一个 `STAFF` 角色），初始密码均为 `learn12345`。先点登录，再挑选商品。所有支付均为模拟，不会扣款。

购物助手（`/assistant`）需要大模型密钥：把 `mall.assistant.deepseek.api-key=sk-xxx` 写进项目根目录的 `.deepseek.key`（已在 `.gitignore` 中），或设置环境变量 `DEEPSEEK_API_KEY`。没有密钥时助手以演示模式运行，会话功能仍可用。

- 运行测试并打包：`mvn clean verify`，Windows 可用 `verify.cmd`。
- 运行已打包应用：`java -jar target/learning-mall-1.0.0.jar`。
- 助手安全评测（需先启动应用与配置密钥）：`MALL_URL=http://127.0.0.1:8093 MALL_BROWSER_CHANNEL=msedge node tests/security-eval.cjs`。
- 停止：启动终端按 `Ctrl+C`。
- 8080 被占用：`java -jar target/learning-mall-1.0.0.jar --server.port=8088`。
- 使用 IntelliJ IDEA：打开本目录的 `pom.xml`，选择 JDK 21，等待 Maven 导入，然后运行 `MallApplication.main`。工作目录设置为项目根目录。
- 数据保存在 `data/mall.mv.db`，重启保留。测试使用独立内存库/临时目录，不改商城数据。

## 你能体验什么

| 功能                             | 能学到的东西                                         |
| -------------------------------- | ---------------------------------------------------- |
| 浏览、搜索、分类、购物车         | MVC、Thymeleaf、JSON、前后端交互                     |
| 三个演示账号登录（含店员）       | Spring Security、Session、BCrypt、CSRF、用户隔离、角色分级 |
| 下单、价格快照、库存预占         | Service/Repository 分层、JDBC、SQL、BigDecimal、事务 |
| 重发上次下单请求                 | 用户范围内的幂等键、请求指纹、数据库唯一约束         |
| 并发抢有限库存                   | 条件 UPDATE、行锁、固定加锁顺序、防超卖              |
| 支付与取消竞争                   | 订单状态机、悲观锁、重复操作幂等                     |
| 超时自动关单与库存回补           | 时间驱动的触发源、状态转换权（影响行数即幂等）、关闭原因区分、定时任务的事务边界 |
| 弃单召回                         | 事务提交后事件（AFTER_COMMIT）、唯一索引做幂等、推荐必须带理由 |
| 两种模拟支付方式                 | 接口、策略模式、IoC 容器集合注入                     |
| 站内通知、投递记录、死信重投     | Transactional Outbox、持久化任务队列、消费幂等       |
| 消息后台处理                     | 定时任务、有界线程池、拒绝策略、退避重试、优雅停机   |
| 操作耗时日志                     | 自定义注解、AOP、代理与自调用问题                    |
| 语音提问、回复自动播报           | Web Speech API、浏览器权限模型、分句合成与打断       |
| AI 助手的注入防护与权限分级      | OWASP LLM Top 10、提示词注入、最小权限、双层守卫、审计留痕 |
| 知识库问答与多租户检索           | RAG、进程内嵌入模型（BGE）、向量检索、检索层租户隔离、间接注入防护 |
| Agent 执行循环与工具编排         | Agent Loop、有界预算与停止条件、并行工具调用、结构化工具错误、上下文裁剪、运行轨迹观测 |
| 助手回答时的实时进度             | SSE、`SseEmitter`、旁路回调（进度不影响安全判定）、`fetch` 读流手工分帧、断流降级 |
| 助手回答的逐字输出               | 流式模型客户端、增量级输出守卫（泄密一到就停）、`done` 携带权威文本覆盖增量 |
| 以图搜款（多模态输入）           | 视觉模型独立于对话模型、`ImageContent` 多模态消息、文件头魔数校验（不信声明的 MIME）、识别失败即如实降级、图片不落库 |
| 降价/补货主动提醒、关联推荐      | 事件驱动 + 定时兜底双触发、`@TransactionalEventListener`、提醒去重与「重新武装」、三级降级推荐 |
| 轮后自动抽取用户偏好             | 规则 + 模型双路径抽取、记忆单一写入路径、来源优先级（推断不覆盖用户原话）、有界队列与冷却 |
| 启动初始化、健康检查、自动化测试 | 自动配置、配置绑定、Flyway、Actuator、JUnit、MockMvc |

这里的消息队列是**数据库持久化任务队列**，提供类似 MQ 的生产、消费、确认、重试、死信流程，未运行独立 RabbitMQ/Kafka 服务。实现边界和升级路径见教程。

## 目录

```text
src/main/java/dev/learning/mall/
├── MallApplication.java       # 启动入口
├── catalog/                   # 商品模块：api / internal / web
├── order/                     # 订单模块：api / internal / web
├── payment/                   # 模拟支付：接口 + 两种策略
├── messaging/                 # 事件发布、线程池、消费者、通知查询
├── assistant/                 # 购物助手：api / internal / web + security（守卫、审计、限流）+ harness（执行循环）
├── proactive/                 # 主动服务：关注、提醒、关联推荐（与助手共用同一套 Service）
├── common/                    # 通用异常、AOP；不包含业务
├── config/                    # 安全装配（账号与角色）
└── web/                       # 页面入口
src/main/resources/
├── templates/                 # Thymeleaf 页面
├── static/                    # CSS、原生 JS、本地 SVG
├── db/migration/              # Flyway 建表、初始商品、助手会话与审计表
└── application.yml            # 数据源、线程池、会话、助手与安全策略等配置
src/test/                      # 事务、并发、安全、恢复测试
tests/                         # 浏览器冒烟测试与安全评测集（供 Java 与 Node 共用）
```

这是**按业务包隔离的单体项目**，不是 Maven 多模块或微服务。跨业务访问走公开接口；包内分层。初学时能一次启动、一次调试，阅读成本低。

## 范围

专注核心学习流程，没有注册、后台运营、物流、优惠券、真实支付（超时订单会自动关闭并归还库存）。商品数据由迁移脚本初始化；购物车与助手记忆存在数据库，订单提交后同样持久化；账号使用内存用户源，数据库和消息为文件持久化。默认只监听本机 `127.0.0.1`，面向本地学习。

技术基线固定为 Java 21 + Spring Boot 3.5.16。查阅对应版本的 [Spring Boot 官方文档](https://docs.spring.io/spring-boot/3.5/index.html)，避免混用 Boot 2 的 `javax.*` 示例。教程中给出了更换数据库、接入 RabbitMQ 和真实支付的进阶方向。
