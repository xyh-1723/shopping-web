## 2026-09-25 项目通读
- 通读 springboot-learning-mall：Java 21 + Spring Boot 3.5.16 单体教学商城，H2 文件库 + Flyway，按业务包隔离（catalog/order/payment/messaging/assistant/common/config）。
- 核心教学点：幂等键+请求指纹唯一约束、条件 UPDATE 防超卖、订单状态机+悲观锁、Transactional Outbox（DB 任务队列+重试+死信）、AOP 计时注解、策略模式支付。
- assistant 模块为后加的 LangChain4j 购物助手（智谱 GLM / DeepSeek，工具调用循环≤5轮，会话消息持久化到 assistant_conversation/assistant_message）。
- 发现问题：application.yml 中 DeepSeek API key 明文硬编码；`model: deepseek-flash` 不是有效模型（有效为 deepseek-chat / deepseek-reasoner）。
- 测试：MallIntegrationTest、AssistantIntegrationTest、DispatcherBackpressureTest、RestartPersistenceTest；另有 Playwright browser-smoke（tests/browser-smoke.cjs）。
